# Ultimate FreeMcBoot Toolkit (ashorizonends)

Separate **modder** installer — not a “dev build.” Same FMCB core as Features; extra tools.

Site: https://ashorizonends.com

## Includes (on top of Features baseline)
- ESR, SMS
- PS2Ident
- Apollo Save Tool
- Memory Card Annihilator
- File Manager (wLaunchELF_R3Z), OPL/wOPL, Controller Tester, Cheat Device, POPStarter

## Card size
Use a larger memory card (~16 MB+). Features is for 8 MB player cards.

## Boot note
SYS-CONF uses stock USB drivers. Optional EXFAT files are under FMCB_EXFAT/ only.
